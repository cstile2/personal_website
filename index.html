Projects
Zeng: a handmade 3D game engine (C/C++/Zig)
This passion project is an entire game engine framework designed to be immediately useful without sacrificing low-level power. By designing it as a modular library, I was able to achieve higher utility, scalability and adaptability. Here's some of what I implemented from scratch:
  • 3D Asset Importer (GLTF/JSON Parser)
    • Parses 3D asset files and imports them into your game application, supporting 3D meshes, animations, textures, and materials.
  • Skeletal Animation Module
    • Full support for 3D animations. Animation blending and transitions are supported.
  • Data-Oriented Entity Component System
    • Objects can have components dynamically added/removed. Different component types get their own contiguous arrays, using memory more efficiently than arrays of structs.
  • OpenGL-Based Renderer
    • OpenGL renderer that uses physically based rendering techniques to create realistic visuals.
  • Physics Collision Module
    • Includes GJK and EPA algorithms, simple raycast and convex shapecast, and novel concave depenetration techniques.
  • Multithreaded Architecture
    • Worker threads are used to process entities in parallel where there aren't data dependencies, audio engine has its own dedicated thread.
  • Networking Module
    • Network messages and RPC's make netcode easy. Battle-test the application by easily simulating packet loss and jitter.
More design details about this project here.
Combat Masters: a fast-paced video-game server and client
This is a game I implemented primarily as a demo for my game engine. A 3D multiplayer game is a great demo because it requires networking solutions that are robust and integrate into complex client-side code.
  • Server Authority
    • Server's state is authoritative, meaning malicious clients cannot tamper with application state.
  • Client-Side Prediction
    • Client interactions that have server latency are predicted immediately, masking network lag.
  • Fast, Reliable UDP Communication
    • UDP protocol is used for optimal performance, but it has reliability issues. Message buffering and redundancy are used to balance between latency and reliability.
